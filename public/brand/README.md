# 제공된 브랜드 자산

- `make-original.png`: 사용자가 제공한 1000×1000 MAKE; PNG 원본.
- `deokyeong-original.jpg`: 사용자가 제공한 1000×1000 덕영고등학교 JPG 원본.

이미지 파일은 변경 없이 복사했습니다. MAKE;의 넓은 바깥 흰 영역은 CSS 뷰포트로 가려 표시합니다. 글자·색·기울기·그림 비율을 변경하지 않습니다. 보이는 MAKE; 그림의 최대 너비는 110px이며 흰 카드 안에 16px 여백을 둡니다. 제품명은 별도 텍스트로 표시합니다.

학교 로고는 홈의 구성원 안내에 사용하며 서비스 운영 주체는 MAKE;로 표시합니다. 제공된 로고의 별도 재배포 라이선스는 확인되지 않았습니다.
